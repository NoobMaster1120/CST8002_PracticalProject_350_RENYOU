LIKELY QUESTIONS — SHORT ANSWERS
============================================================
Q: Why did you choose an API/library?
A: I used free matplotlib for the vertical bars. My own code still does
   aggregation in RecordService from the singly linked list. Presentation
   only asks the user options and calls the chart view.

Q: Why not write all chart logic yourself?
A: ASCII fallback is my own console chart. Matplotlib is free/open-source
   and better for a clear vertical bar chart demonstration.

Q: Where is the layering?
A: Menu (presentation) -> RecordService.aggregate_original_value_by
   (business) -> linked list records (model) -> chart_view render
   (presentation). Not one giant method.

Q: What was Part 3 topic?
A: Custom Singly Linked List replacing Python list for in-memory records.
